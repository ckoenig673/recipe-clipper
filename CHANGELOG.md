# Changelog

## [1.0.0] - 2026-11-12

Initial public release baseline.

- Added recipe import support for public URLs, pasted full-text recipes, uploaded images with OCR, shared social-video links, and fully manual recipe entry.
- Added optional AI Cleanup for saved recipes, including a review flow that shows structured proposed changes before users apply them.
- Added cookbook organization, bulk recipe actions, meal planning, grocery preview generation, checked grocery lists, and grocery cleanup by recipe source or completed items.
- Added authentication and security improvements, including login protection, personal account and import settings management, and admin security settings coverage in the app.
- Added backend and frontend regression coverage, including backend fixtures/tests plus Playwright coverage for authentication, URL import, OCR import, pasted recipes, AI Cleanup review, mobile behavior, cookbook layout, and bulk recipe actions.
- Added public release documentation covering feature scope, environment setup, architecture, contribution workflows, and security reporting for the `1.0.0` baseline.
