# Recipe Clipper v1.0.0

Recipe Clipper `v1.0.0` is the initial public source release of the self-hosted recipe capture, organization, planning, and grocery workflow.

## Highlights

- Import recipes from public recipe URLs, pasted text, uploaded images, and public social-video links.
- Review and edit normalized ingredients, instructions, times, servings, notes, and source information before saving.
- Organize recipes into cookbooks and use bulk recipe actions.
- Plan meals and generate grocery previews and persistent grocery lists.
- Use optional Ollama-assisted cleanup with a structured review step before applying changes.
- Share supported links from Android through the included companion source project.

## Security and Privacy

- Invite-only authentication with one-time bootstrap administrator credentials.
- Per-user recipe, cookbook, meal-plan, grocery, and import-setting data boundaries.
- Login lockout controls and administrator security settings.
- Server-side validation for public URL imports and sanitized recipe extraction.
- CodeQL, Dependabot, secret scanning, push protection, and protected `main` checks enabled for the repository.

Recipe Clipper remains self-hosted. Operators are responsible for TLS termination, host access, backups, secret management, and the security of optional external services such as Ollama.

## Deployment

This release is distributed as source. Build the five-service stack locally with Docker Compose after reviewing `.env.example` and the [deployment guide](../deployment/README.md).

Before the first login, replace the example bootstrap password. After the first successful administrator login, remove the bootstrap email and password from `.env` and redeploy.

Persistent data lives under the deployment's `data/` directory. Back it up before upgrades or restore operations.

## Included Components

- FastAPI backend and SQLite persistence
- nginx-hosted JavaScript frontend/PWA
- Tesseract OCR worker
- yt-dlp social-download worker
- faster-whisper transcription worker
- Android share companion source `0.2.1`

## Distribution Notes

- GitHub source archives are the only planned `v1.0.0` artifacts.
- No prebuilt container images are published with this release.
- No Android APK is published with this release.
- The documented application version is `1.0.0`; the Android companion follows its own version sequence.
