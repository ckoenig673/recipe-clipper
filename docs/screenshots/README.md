# Screenshot Standards

Product screenshots must be captured from a local demo environment containing synthetic recipes and accounts.

Before committing a screenshot, verify that it contains none of the following:

- Real names, email addresses, accounts, or invitation details
- Private recipe text, cookbook names, meal plans, or grocery lists
- Hostnames, IP addresses, filesystem paths, cookies, or tokens
- Ollama endpoints, worker URLs, logs, or environment values

Preferred initial views:

1. Recipe library populated with synthetic recipes
2. Recipe detail with sanitized ingredients and instructions
3. Import review showing deterministic structured fields
4. Meal plan or grocery list containing synthetic data

Use PNG or high-quality JPEG format, crop browser chrome unless it provides useful context, and keep the viewport wide enough for README rendering. Keep the existing login screenshot only as an authentication reference; the primary README image should show the product after sign-in.
